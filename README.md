## 简介

把浏览器新标签页换成一个好看的导航站：一组常用链接、一个搜索框、一层会动的背景。仓库提供两个版本，可按喜好二选一部署。

## 功能

- **双版本**：动态背景版（背景流动、玻璃质感）与拟态设计版（柔光凹凸、克制的单色）
- **卡片分组**：常用站点按类目排布，一屏看全
- **搜索直达**：顶部搜索框，回车即跳转
- **纯静态**：改 `index.html` 里的链接即可，无需后端
- **响应式**：手机与桌面自适应

## 快速开始

```bash
git clone https://github.com/aiyangdie/Dynamic-Background-Navigator.git
```

- 动态背景版：打开根目录 `index.html`
- 拟态设计版：打开拟态版入口文件

## 项目结构

```
index.html        动态背景版
css/              两版样式
js/               背景动画与交互
```
